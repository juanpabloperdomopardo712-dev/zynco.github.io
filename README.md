# Zynco

Aplicación web con base de datos desarrollada como proyecto académico/personal.

## ¿Qué hace?
- Gestiona información conectada a una base de datos (`zynco_db.sql`) con interfaz web (`index.php`, `css`, `js`, `php`).

## Mi aporte en el proyecto
- Diseño y estructuración de la base de datos.
- Maquetación e interfaz web.
- Gestión e integración de funcionalidades apoyándome en inteligencia artificial.

## Tecnologías presentes
- SQL, HTML, CSS, JavaScript y PHP.
