# Zynco

Gestor de bases de datos web desarrollado como proyecto productivo final del técnico en Programación de Software (SENA), diseñado para ser práctico, intuitivo y fácil de usar.

## Funcionalidades principales
- Sistema de roles para empleados.
- Registro y gestión de clientes y vehículos.
- Carga e inserción de imágenes.
- Conexión y gestión de datos respaldada por base de datos (`zynco_db.sql`).

## Mi rol en el proyecto
- Idea original, planteamiento general y estructura del sistema.
- Diseño y organización de la base de datos.
- Dirección y gestión del desarrollo, orientando el código con apoyo de inteligencia artificial.

## Tecnologías utilizadas
- SQL, HTML, CSS, JavaScript y PHP.
